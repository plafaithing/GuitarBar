# GuitarBar 项目关键要求

## 曲谱渲染（TabView）布局铁律

- **小节归属**：每小节的所有音符（含 label 与全部标注符号）必须留在本小节
  竖线范围内，**不允许视觉上跳出到相邻小节**。
- **小节线保护**：任何音符 label / 标注**不得遮挡小节两侧竖线**，与竖线
  保持 **≥ 5px** 距离。【目标规则——实现暂缓：2026-11-09 实测强制钳制会
  连锁引发 tap 连线错位与音重叠，待排布算法整体升级（按小节内容自适应
  宽度）后再启用】
- **同拍对齐**：同一拍（beat 相同）的跨弦音符必须垂直对齐（同一 x），
  表示同时发声；同弦相邻防重叠逻辑不得破坏该对齐。
- **不同拍不同列**（2026-11-18 用户铁律；2026-11-25/26 补充口径）：小节内
  **不同 beat 的音不得同列**（含跨弦——x 相同或**近似**同列即违例：
  x 差小于可分辨宽度也算）。缓解手段 = **减少该行小节数（折行）**，
  不可因紧凑让不同拍音挤到同列/近似同列。排布移动（链推/挂靠让位/
  钳制）不得破坏拍序可读性：早拍音必须在晚拍音左侧保持可分辨的
  间隔；任何排布改动后跑重叠探针须同时校验此条。
  - 近似同列口径（唯一来源 `TabLayout.nearColNeed` / `nearColExempt`）：
    非豁免对的中心距须 ≥ **两音标签墨半宽的较大者 + 4px**——即任一
    音的中心不落入另一音的标签范围。**按标签实际墨宽，不用定值**
    （2026-11-27 用户实测校准：定值 18px 是拿 LSA `<12>` 校准的，套
    到一位数上过严——Bluebird m1–m3 十六分对隔两根弦、字边还有 8px
    空隙却被判同列；月下之恋 m8–m11 四小节一行可接受）。一位数→
    一位数 ≥8.3px；`2`→`<12>` ≥24px（比旧口径更严）；`<12>`→`<12>`
    ≥24px（LSA m1 级联保留）。须与 x 序上**所有够得着的**非豁免前驱
    比较（含同拍同 x 的宽标签兄弟）。豁免（按**拍序**判）：grace 不
    进校验；亚拍错位（拍差 **< 1/16**，1/32 级装饰错位——装饰对
    `<12>^2` 等，gp8 同款）；前一个拍为装饰性短音（dur ≤ 0.15）。
    被豁免的中间音只让自身那几对免检，两端构成的非豁免对仍须校验。
    1/16 及以上拍差一律严格（连音/三连音可读性）。
  - 判定方式（2026-11-27 闭环求解）：折行不靠解析公式近似——调渲染
    paint **同一个排布函数**（`buildRowFlow`）预测候选行的排布终位，
    在终位上校验铁律；违例小节加宽重试，确实放不下才折行。**合并的
    判据 = 预测渲染干净**。布局层与渲染层的排布口径必须同源（手写
    近似链模拟已撤除——它漏掉行首贴线、挂靠让位、deco 左槽、左推
    级联，行越紧偏差越大）。行内小节宽：先保物理最小宽，剩余按拍
    列数加权，宽比超 2.4 削峰填谷（不削破最小宽）。
- **数字不重叠**（2026-11-16 用户铁律）：小节内的数字、`(数字)`、
  `<数字>` 等 label 展示形式**互不重叠、不被任何符号遮挡**（含字母/
  点/箭头等标注与相邻音 label）。弧上标注（"sl"/H/P）与 L.R./P.M.
  带标签须经占用判定找空位，全占则不画该标注（弧/斜线保留）——
  2026-11-27 全量探针实证 "sl" 落在上一弦弦线高度压数字。探针的结构性
  豁免只剩一类：独占整行仍违例的被迫行（"含 grace 行即豁免"同日撤除
  ——折行判定已与 paint 共用排布函数，预测即渲染）。任何排布/
  标注改动后必须跑**重叠探针**（按 paint 同款墨宽几何计算 label 盒
  相交）验证，不能只跑测试套——多轮改完仍现重叠的教训固化。
- **播放/命中位置与音实际渲染位置一致**（2026-11-25 用户铁律）：点击
  命中、播放定位的坐标必须与**渲染坐标同源**（dup 错开/装饰槽位/
  拥挤让位后的实际 x，即 lastFlow），拍位基础坐标（noteX）只作
  谱面未画帧的兜底。命中位置与视觉位置分离即 bug。
- 泛音显示用尖括号 `<品>`（gp8 同款）；人工泛音加 AH 文字标注。
- 除最后一行外，每行最少2小节，最多5小节；规则允许下**尽量多的小节数**
  （用户 2026-11-25/26：不希望出现单小节行/可合并未合并），但不允许
  超宽小节（行内最大/最小小节宽比 ≤ 2.5）。密度档按**拍列数**（去重
  beat 数）而非音符数——和弦谱音符数远大于列数。

## 数据修正原则

- 源 gpx/gp5 个别小节的节拍/弦位错误，在解析层做**精准特例修正**
  （注释标明曲名/位置/原因），不做无依据的通用推断；修正处必须
  有 gp8 显示/听感证据。
