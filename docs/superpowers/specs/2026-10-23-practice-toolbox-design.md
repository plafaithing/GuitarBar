# GuitarBar · 第一期「练琴工具箱」设计文档

- 日期：2026-10-23
- 状态：设计已与用户逐节确认
- 目标平台：Windows 打样 → iPad Pro 11 寸（最终主力使用设备）

## 1. 背景与定位

个人自用练琴工具。现有软件（如 GuitarTuna）的痛点：自定义调弦只能保存 3 个。
本项目调弦预设不限量，并以 iPad 平板支架练琴场景为第一设计目标。

## 2. 总体路线（三期）

| 期 | 内容 | 说明 |
|---|---|---|
| 一 | 练琴工具箱（本文档） | 调音器 / 调弦预设 / 和弦库 / 指板音阶 / 节拍器 / 打卡 |
| 二 | 曲谱库 + 识谱 + 自动演奏 | 六线谱识别走多模态大模型 API + 人工校对界面；自动演奏复用一期音频引擎 |
| 三 | 3D 指法演示 | 视频时间段定位 + 3D 多角度慢放；指法动画数据来源届时评估 |

分期原则：音频引擎、数据层、平板 UI 框架为三期共用底座，一期负责打地基。

## 3. 技术栈与架构

**技术栈：Flutter（已定）**。理由：Windows + iPadOS 单代码库；Dart 对 Java
背景友好；自绘 UI（指板、和弦图、频谱）与音频插件生态成熟。

```
UI 层（3 个 tab + 工具箱子页面）
业务逻辑层（YIN 音高检测 / 节拍音频时钟调度 / 乐理模块 / 打卡统计）
音频引擎（麦克风采集 ↔ 播放输出；调音器、节拍器共用，二期自动演奏复用）
数据层（本地 SQLite，drift）
```

- 音高检测：YIN 算法，纯 Dart 实现，便于调试和 review
- 节拍器调度：基于音频时钟而非系统定时器，杜绝漂移
- 平台相关代码（麦克风权限等）隔离在平台适配层，iOS 权限配置文档化

## 4. 页面结构与导航

底部导航 3 个 tab；iPad 横屏 / 宽窗口时同一套 3 项切换为左侧边栏（NavigationRail）。

```
├── 🎸 调音器（一级入口，高频核心）
│   ├── 模式切换：吉他模式 | 半音调音器
│   └── 调弦预设选择 / 管理（页内完成）
├── 🧰 工具箱（功能容器，入口卡片式）
│   ├── 和弦库
│   ├── 指板音阶
│   ├── 节拍器
│   └── （后续新工具在此扩展）
└── 👤 个人中心（打卡记录、统计、后续扩展位）
```

**全局练习计时**：点击"开始练习"后计时器顶栏常驻，切换任意页面不受影响；
结束时自动生成一条打卡记录。

## 5. 功能设计

### 5.1 调音器 + 调弦预设管理

- **双模式**：
  - 吉他模式：按当前调弦预设工作，弹任意弦自动识别是哪根弦、偏差多少
  - 半音调音器（Chromatic）：不预设弦，识别任意音高显示音名
- 调音界面：大字音名 + 指针摆动（±50 音分），调到位变绿；支持手动锁定单弦
- **内置预设 20 种**（音高为科学记谱，6 弦从低到高）：

| 预设 | 音高 |
|---|---|
| Standard | E2 A2 D3 G3 B3 E4 |
| Half Step Down | Eb2 Ab2 Db3 Gb3 Bb3 Eb4 |
| Full Step Down | D2 G2 C3 F3 A3 D4 |
| 1.5 Steps Down | C#2 F#2 B2 E3 G#3 C#4 |
| Two Steps Down | C2 F2 Bb2 Eb3 G3 C4 |
| Drop D | D2 A2 D3 G3 B3 E4 |
| Drop C | C2 G2 C3 F3 A3 D4 |
| Drop B | B1 F#2 B2 E3 G#3 C#4 |
| Drop A | A1 E2 A2 D3 F#3 B3 |
| Open D | D2 A2 D3 F#3 A3 D4 |
| Open E | E2 B2 E3 G#3 B3 E4 |
| Open G | D2 G2 D3 G3 B3 D4 |
| Open A | E2 A2 E3 A3 C#4 E4 |
| Open C | C2 G2 C3 G3 C4 E4 |
| Open F | F2 A2 C3 F3 A3 F4 |
| Open D Minor | D2 A2 D3 F3 A3 D4 |
| DADGAD | D2 A2 D3 G3 A3 D4 |
| Modal D | D2 A2 D3 E3 A3 D4 |
| Nashville (High Strung) | E3 A3 D4 G4 B4 E5 |
| All Fourths | E2 A2 D3 G3 C4 F4 |

- **自定义预设**：数量不限；编辑器 = 命名 + 六弦逐个选音高；
  内置预设可复制后修改（原件不可删），自定义可增删改

### 5.2 和弦库

- 输入和弦名（Am7、F#m7b5 等均可）→ 乐理算法实时生成多个指法，按易到难排序
- 不依赖静态指法数据库：任意生僻和弦可查，且随调弦预设联动重算
- 指法图：品位格 + 手指序号 + 起始品标注；点按发声试听

### 5.3 指板音阶

- 根音 + 音阶类型（大调 / 自然小调 / 大小调五声 / 布鲁斯等）
- 指板高亮显示，跟随调弦预设联动；点任意品位发声
- 音名 / 唱名显示可切换

### 5.4 节拍器

- BPM 30–300；拍号 2/4、3/4、4/4、6/8；强拍重音 + 节拍指示灯
- 音频时钟精确调度（单测保证节拍间隔精度）

### 5.5 个人中心（打卡）

- "开始练习" → 顶栏常驻计时 → 停止自动记录（日期、时长）
- 忘记开计时支持手动补卡
- 日历热力视图 + 本周 / 本月总时长 + 连续天数
- 全部数据本地存储

## 6. 数据层设计

- SQLite（drift），三张表：
  - `practice_sessions`：开始时间、结束时间、时长、备注
  - `tuning_presets`：自定义调弦（内置预设打包在代码资产中，不入库）
  - `settings`：应用设置
- **导出 / 导入 JSON**：Windows 打样期数据一键迁移到 iPad 的通道

## 7. 错误处理

- 麦克风权限被拒 → 引导页说明并跳系统设置
- 音频设备不可用 → 明确提示；节拍器、和弦试听等纯输出功能不受影响

## 8. 测试策略

| 必须 | 内容 |
|---|---|
| 单测 | YIN 音高检测（合成标准频率波形喂入，断言检测结果） |
| 单测 | 节拍器音频时钟调度间隔精度 |
| 单测 | 乐理模块（和弦名解析、指法生成、音阶计算） |
| 单测 | 数据层增删改查、JSON 导出导入 |
| 手动 | UI 交互、双端窗口/布局验证 |

## 9. 范围外（YAGNI）

云同步、账号体系、谱识别与自动演奏（二期）、3D 演示（三期）、
Bass/尤克里里等其他乐器预设（未来需要时预设结构加字段即可）。

## 10. 验收标准

1. Windows 运行，默认窗口为 iPad 比例，宽窗口自动切换侧边栏导航
2. 对麦克风弹弦，调音器正确显示弦名与音分偏差，到位变绿
3. 半音模式可识别任意单音音名
4. 内置 20 种预设齐全；自定义预设增删改查不限数量，重启后保留
5. 查询 Am7、F#m7b5 等和弦返回指法图并可试听
6. 切换 Drop D 等预设后，指板音阶、和弦指法随之联动
7. 节拍器长跑 5 分钟无可感知漂移
8. 打卡：开始练习 → 切页 → 停止，记录正确；日历统计、连续天数正确
9. 导出 JSON → 清空数据 → 导入，恢复一致
