# GuitarBar 🎸

个人自用练琴工具箱。以 **iPad 支架练琴场景**为第一设计目标，Windows 打样，将来一套代码编译到 iPad。

## 功能

### 第一期 · 练琴工具箱 ✅

| 功能 | 说明 |
|---|---|
| 🎸 调音器 | 吉他模式（按调弦预设自动认弦）+ 半音调音器（识别任意音高）；目标环随音分左右滑动、到位变绿；**音名胶囊显示上次音名平滑淡出**（声音断续不闪空壳）；布局自适应（网格区吃满剩余视口、内容垂直居中、吉他贴设备栏）；输入设备可选、诊断面板（调试模式开关，release 也生效） |
| 调弦预设 | 内置 20 种分五组（标准/降调、Drop、Open、特殊、自定义）；自定义**不限量**：逐弦选音、命名保存、复制内置预设 |
| A4 校准 | 430–450 Hz 可调，持久化 |
| 参考音 | 点击弦块播放该弦参考音（Karplus-Strong 拨弦合成：软激励 + 拾音位置梳状滤波） |
| 🧰 和弦库 | 和弦名解析 → 按当前调弦实时生成指法（算法生成，非静态库），指法图 + 琶音/扫弦试听；输入/浏览双模式 |
| 🎹 指板音阶 | 根音 + 音阶 → 指板高亮，随调弦联动，点按发声 |
| 🥁 节拍器 | 30–240 BPM 转盘（点按定位 + 绿球拖动连续调速）、拍号、细分拍、Tap Tempo；整轨循环零漂移调度 |
| 👤 练琴打卡 | 全局练习计时（切页不断、关窗自动保存）、日历、手动补卡 |
| 数据 | 本地 SQLite（应用自身目录，含启动自动迁移）；JSON 导出/导入 |

### 第二期 · 曲谱库 + 自动演奏 ✅

| 功能 | 说明 |
|---|---|
| 📚 曲谱库 | 导入 `.gpx/.gp5/.gp3/.gp4/.gtp/.pdf/图片`（单文件/多选批量/文件夹多图合成且**可调顺序**），**同类型**同名自动连加（`a.gpx` 与 `a.pdf` 互不干扰，Windows 语义）；**实时搜索** + 类型筛选；首字母分组排序（英文优先、中文拼音）+ 字母索引条；iOS 式交互——**多选批量删除、左滑操作、长按卡片预览**（GTP 直接渲染谱面）、回收站（软删 30 天自动清） |
| 🎼 GTP 精确解析 | `.gpx`（GP6/7 gpif，BCFZ 位级 LZ 自解压）+ `.gp5`（二进制逐字节移植 PyGuitarPro）+ **`.gp3/.gp4`（GP3/GP4 二进制）+ `.gtp`（GP1/2 老格式）**：音符/技法/装饰音/调弦/tempo/Fermata 延长记号全量解析——确定性数据，无 AI 置信度；魔数路由（zip/BCFZ/gp5/gp34/gtp12 二进制自动分流，全曲库 3409 文件扫描 + PyGuitarPro 双向对账零炸点） |
| ▶️ 自动演奏 | **真录钢弦采样**逐音调度（114 采样：拨弦/泛音/闷音/击勾分片归一，非 6 弦谱自动降级合成音色）；演奏反复展开（Repeat/跳房子）；Fermata 延长记号按记谱语义（标记音准时拉长、其后顺延，播放指针与发音同一条时间轴）；**X/8 拍号四分拍口径统一**（6/8 等复合拍小节时长/播放头全链正确，无小节末空白）；**插针语义**——停止/暂停态点音只插针不播（指针精确落在点的音上）、点播放从该处起，播放中点音即时跳转；同弦连拨叠振不断音（主流制谱软件行为对照实证） |
| 🎯 演奏技法全映射 | 琶音（依次发声）、扫弦（依次错开）、击勾弦（弱击）、滑音（PitchShift 连续滑，连滑斜线+弧+sl 三件套）、揉弦（音高往复）、颤音（大二度交替）、震音拨（32 分）、断音/幽灵音/重音（音量与时值映射）、**装饰音（GP 装饰数据解析，独立音符一闪滑入主音）**、泛音（音高重映射到分节点，坏点采样 FFT 实测剔除 + 跨弦借采）、弯音/摇把（曲线 ramp）、闷音、力度（Velocity/Dynamic/Fade）、Let Ring |
| 🔁 跟练三件套 | **实时变速 0.25–2.0 八档**（播放中在线重锚无缝、进度轴全速率统一）；**渐进提速**（AB 循环每 3 遍 +5% 自动爬到原速）；AB 循环（**谱面区段高亮 + A/B 端线标记**，长按音符设点）；进度拖动 |
| 🔗 链接备注 | 每份曲谱可挂教学/视频网址，详情页一键跳浏览器（自动补 https） |

### 谱面渲染（六线谱，主流制谱软件 1:1 观感基准）

折行 = **闭环求解**：调渲染同一个排布函数预测候选行的排布终位，在终位上校验铁律（数字不重叠/不同拍不同列/时序），违例小节加宽重试，确实放不下才折行——**合并的判据 = 预测渲染干净**，行分布"规则允许下尽量多小节数"（单小节行近零）；"不同拍不同列"按**标签实际墨宽**判（一位数 ≥8px、`2`→`<12>` ≥24px，亚拍装饰错位豁免）；行内小节宽先保物理最小宽、剩余按拍列数加权、宽比削峰填谷。播放指针 60fps 直连渲染层，命中/插针/播放定位与渲染坐标同源。连音弧画在数字头部上方（不遮数字）；**tie 延续音三态**（逐弧对照实证定案：跨小节续接 `(N)`、小节内隐藏、装饰拍裸数字锚，TAB 行不画 tie 弧）；**装饰音独立槽位**（主音左侧，sl 弧连向主音）；泛音 `<12>` 尖括号、L.R./P.M. 虚线段式标注、反复记号「点｜细｜粗」规范形态、T 点弦谱顶椭圆；同拍跨弦垂直对齐 + 小节归属（越界零容忍，全曲库重叠探针违例 0）。图片/PDF 源谱查看器横竖双模式随时切换、循环翻页带回绕提醒。

## 技术栈

- **Flutter**（Windows 打样 → iPad）— 单代码库，一套交互双端复用
- **音频**：`record`（麦克风 PCM 流）→ **YIN 音高检测**（纯 Dart，谐波鲁棒、无八度错误）；`flutter_soloud`（低延迟引擎）+ Karplus-Strong 拨弦合成 + **真录钢弦采样库**（逐音调度/PitchShift 滑音揉弦/力度映射）+ 采样精确整轨循环
- **乐理**：纯 Dart——科学记谱解析、20 组内置调弦、算法化和弦指法生成（任意生僻和弦可查、随调弦联动）、音阶引擎、GTP 全家族（gpx gpif / GP5 / GP3/4 / GP1/2）二进制与 XML 解析
- **数据**：drift + SQLite（schema v4，软删回收站）；数据根候选链（exe 旁 `data\` → Documents 兜底）+ 启动自动迁移
- **UI**：v2「aurora-dark」设计语言（参考 reactbits.dev：统一光晕背景层 + 玻璃浮层 + 琥珀数据色 #8a5a2b）——全产品单一风格；曲谱库交互对齐 iOS 信息 app

## 开发

```bash
flutter pub get
flutter test --exclude-tags=heavy   # 日常套 310 项（乐理/解析器/音频算法/播放映射/布局求解/数据迁移/widget）
flutter test                        # 终验全量（含全库重叠探针 + 解析器全量对账）
flutter run -d windows
```

**发布打包**（解压即用便携 zip，内置卸载器与使用说明）：

```powershell
powershell -File packaging\build.ps1              # 编译 + 打包
powershell -File packaging\build.ps1 -SkipBuild   # 只重新打包（跳过编译）
```

产物：`dist\GuitarBar-<日期>.zip`。

要求：Flutter 3.47+、Windows 开发者模式（构建符号链接）、Visual Studio C++ 桌面工具链。

## 工程方法

TDD（合成波形验证 YIN、解析器真值对账、播放映射合成 fixture）；外部 AI（dsh）交叉语义审查 + 本地全量测试双保险；gpx/gp5 探针脚本扫真实样本定数据形态；设计决策与教训沉淀在 git 历史与 `tasks/lessons.md`。
