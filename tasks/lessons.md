## 2026-10-29 二期设计（识谱 API）

- **场景**：二期识谱设计我默认锚定 GLM（因为用户 zai key 现成），用户纠正："未来 iOS/Windows 不能只用 glm 模型，支持可以使用其他模型"，并要求专门的模型配置页。
- **教训**：设计外部服务依赖时，"当前恰好有 key 的服务"不等于"设计上绑定的服务"。个人工具也要留多厂商出路。
- **规则**：凡涉及外部 API 的设计，默认按通用协议（如 OpenAI 兼容格式）+ 可配置页设计，厂商只作为预置模板出现；不把单一厂商写进架构假设。
